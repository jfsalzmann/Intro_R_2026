Why not base R?

Every plot() call starts from a blank canvas — no axis labels worth reading by default, no legend, no way to color by group without writing it by hand. ggplot2 builds a plot in layers instead, so from here on we use it exclusively.

The grammar of graphics

Every ggplot starts from a blank canvas, built up step by step with +.

ggplot(polls)
ggplot(afd, aes(x = Date, y = share))
afd |>
  ggplot(aes(x = Date, y = share)) +
  geom_point()

Scatter plots

One point per poll, colored by pollster.

afd |>
  ggplot(aes(x = Date, y = share, color = Pollster)) +
  geom_point(alpha = 0.6)

Add labels, change axis breaks, and set limits.

afd |>
  ggplot(aes(x = Date, y = share, color = Pollster)) +
  geom_point(alpha = 0.6) +
  scale_y_continuous(
    breaks = seq(15, 30, by = 5),
    labels = c("15%", "20%", "25%", "30%"),
    limits = c(15, 30)
  )

A handy shortcut: format the y-axis as percent directly (share needs dividing by 100 first).

p_load(scales)

afd |>
  mutate(share = share / 100) |>
  ggplot(aes(x = Date, y = share, color = Pollster)) +
  geom_point(alpha = 0.6) +
  scale_y_continuous(breaks = breaks_width(.05), labels = label_percent())

Line plots

Connecting raw polls in order is noisy with this much day-to-day variation — we reduce the plotted timeframe by filtering first.

afd |>
  filter(between(Date, as.Date("2026-01-01"), Sys.Date())) |>
  ggplot(aes(x = Date, y = share)) +
  geom_line()

A line plot makes more sense per pollster.

afd |>
  filter(between(Date, as.Date("2026-01-01"), Sys.Date())) |>
  ggplot(aes(x = Date, y = share, color = Pollster)) +
  geom_line()

A smoothed trend line reads much better — roughly what a “polling average” tracker shows (their exact weighting scheme is more involved than this).

afd |>
  ggplot(aes(x = Date, y = share)) +
  geom_point(alpha = 0.3) +
  geom_smooth(span = 0.2, se = FALSE)
`geom_smooth()` using method = 'loess' and formula = 'y ~ x'

Boxplots

Spread of a party’s polled share per pollster — “house effects”.

A smoothed version of the same distribution.

Saving plots

ggsave() saves the last plot drawn, or a specific one via plot = .... width/height set the physical size, dpi the pixel density — dpi only matters for raster formats like PNG, a PDF is a vector graphic with no fixed resolution.

trend_plot <- polls |>
  ggplot(aes(x = Date, y = share, color = party)) +
  geom_smooth(se = FALSE) +
  scale_color_manual(values = party_colors) +
  labs(title = "Bundestag polling trend", x = NULL, y = "Share (%)", color = "Party")

ggsave("afd_trend.png", plot = trend_plot, width = 7, height = 5, dpi = 300)
ggsave("afd_trend.pdf", plot = trend_plot, width = 7, height = 5)

Pie plots

ggplot2 has no dedicated pie geom — it is a bar chart bent into a circle.

latest_forsa |>
  ggplot(aes(x = "", y = share, fill = party)) +
  geom_col() +
  coord_polar("y") +
  scale_fill_manual(values = party_colors)

(`geom_col()`).

Angles are harder to compare at a glance than bar height — the bar chart above communicates the same numbers more clearly.

Groups

A second mapped variable (color, fill, or group) clusters bars side by side automatically.

polls |>
  filter(Date == max(Date)) |>
  ggplot(aes(x = party, y = share, fill = Pollster)) +
  geom_col(position = "dodge")
Warning: Removed 1 row containing missing values or values outside the scale range
(`geom_col()`).

color only outlines the bars — for geom_col() you almost always want fill.

polls |>
  filter(Date == max(Date)) |>
  ggplot(aes(x = party, y = share, color = Pollster)) +
  geom_col(position = "dodge")
Warning: Removed 1 row containing missing values or values outside the scale range
(`geom_col()`).

group alone still dodges the bars into position, just without any visual distinction between them.

polls |>
  filter(Date == max(Date)) |>
  ggplot(aes(x = party, y = share, group = Pollster)) +
  geom_col(position = "dodge")
Warning: Removed 1 row containing missing values or values outside the scale range
(`geom_col()`).

Color/fill and group don’t have to match — group decides which points geom_line() connects, independently of what color encodes.

polls |>
  filter(between(Date, as.Date("2026-01-01"), Sys.Date())) |>
  ggplot(aes(x = Date, y = share, color = party, group = paste(Pollster, party))) +
  geom_point(alpha = 0.4) +
  geom_line(alpha = 0.4) +
  scale_color_manual(values = party_colors) +
  labs(title = "Same color, grouped by pollster x party", x = NULL, y = "Share (%)", color = "Party")
